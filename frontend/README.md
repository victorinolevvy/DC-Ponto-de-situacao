# Frontend - Ponto de Situação

Aplicação React simples utilizando CDN.

Abra `index.html` em um navegador. Certifique-se que o backend esteja executando em `http://localhost:3001`.

A área de filtros permite pesquisar projetos por província, gestor, objecto ou estado.

Use os botões "Exportar Excel" e "Exportar CSV" para baixar os dados.
